# Konekta: Your Service Connection

KONEKTA

Plataforma Inteligente de Prestação de Serviços para São Tomé e Príncipe

Versão: MVP 1.0

O que é o KONEKTA?

O KONEKTA é uma plataforma digital que liga pessoas que precisam de serviços a profissionais qualificados de forma rápida, segura e organizada.

O KONEKTA não é apenas uma lista de prestadores.

É um intermediário de confiança.

Toda a comunicação, pagamentos, histórico e acompanhamento acontecem dentro da plataforma.

O objetivo é digitalizar o mercado de prestação de serviços em São Tomé e Príncipe.

Problema

Hoje em São Tomé e Príncipe existe muita dificuldade para encontrar profissionais de confiança.

Normalmente as pessoas:

perguntam aos amigos;

procuram no Facebook;

procuram no WhatsApp;

procuram em grupos.

Os problemas são:

pouca confiança;

preços sem transparência;

atrasos;

golpes;

falta de garantias;

não existe histórico;

não existe suporte.
